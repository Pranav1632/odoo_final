# PeoplePay360 — Product

**Mission:** A calm, paper-calm payroll desk for HR operators — run payroll, manage people, stay compliant, without the navy fintech dashboard noise.

**Audience:** HR managers, payroll admins, small-business owners who run payroll weekly/monthly. Desktop-first, daytime office light.

**Core jobs:**
- Scan net-pay totals, headcounts, attendance health at a glance
- Spot exceptions (missing bank details, overdue payruns, balance warnings) and act
- Browse, filter, create employees, contracts, payruns, time-off requests
- Approve/refuse time-off with balance visibility
- Generate payslips & PDF

**Constraints:**
- Desktop Operate mode; mobile read-only acceptable
- No dark mode (daytime tool; nomu aesthetic is light-only)
- Single accent (coral #FF7448) carries action weight; no competing colors
- Inter font (user requirement; nomu uses it)
- No external icon library — SVG inline, pill-radius grammar

**Non-goals:**
- Multi-tenant SaaS chrome, org switching, audit logs, role matrix
- Real-time collaboration, notifications center, websocket feeds
- Internationalization beyond US date/currency formats
- Dark theme, high-contrast, color-blind palettes (not briefed)

**Brief pin:** Visual world = nomu.store (cream ground #FFF9F6, ink #0F151D, coral acts #FF7448, pill surfaces, Inter medium-weight). This world is the directive, not a reference.
